# Portfolio Site Improvements

Ideas for leveling up the site and deepening its value as a hiring/consulting signal.

## Analytics & Insights
- [ ] Wire up Heap analytics to understand which case studies / sections recruiters engage with
- [ ] Add UTM tracking to LinkedIn and email links to see referral sources
- [ ] Monitor time-on-page and scroll depth for each case study
- [ ] Track CTA click rates (email, LinkedIn)

## Case Study Depth
- [ ] Add a "Outcomes & Learnings" subsection to each case study highlighting what stuck with you
- [ ] Include a "Role & Constraints" section up front so readers know scope vs. broader org
- [ ] Add links to shipped products (where public) or demo videos
- [ ] Consider adding a "What I'd Do Differently" reflection for older cases

## Narrative & Positioning
- [ ] Add a "What I'm Building Now" or "Current Focus" section to signal forward momentum
- [ ] Create a short "Hiring/Consulting" CTA page for recurring inbound interest
- [ ] Add a "Speaking & Writing" section if you've done talks, podcasts, or published pieces
- [ ] Consider a brief "North Star" statement—what problems excite you most

## Social Proof & Credibility
- [ ] Add 1–2 short testimonials from peer PMs or engineering partners (if willing)
- [ ] Link to LinkedIn recommendations or endorsements
- [ ] Add publication links (if applicable) or bylines on case studies

## Technical & SEO
- [ ] Add meta descriptions and OG tags to each case study for better link previews
- [ ] Optimize heading hierarchy (h1/h2/h3) for semantic structure and SEO
- [ ] Add schema.org markup for portfolio/person data
- [ ] Review Core Web Vitals and performance budget

## Design & UX
- [ ] Add subtle animations on scroll (fade-in, counter animations for metrics)
- [ ] Create visual "before/after" comparisons for key outcomes where relevant
- [ ] Consider a dark mode toggle (already set up in CSS with theme variables)
- [ ] Add breadcrumb navigation on case study pages for easier backtracking

## Content Expansion
- [ ] Publish a "Tools & Stack" page (Figma, SQL, Python, Claude, etc.)
- [ ] Add a reading list or recommended resources (books, papers, frameworks)
- [ ] Create a "FAQs" page answering common recruiter questions (Are you open to roles? Timeline? Scope?)
- [ ] Start a "Shipping Log" or weekly updates on what you're working on

## Engagement & Funnel
- [ ] Add a newsletter signup (Substack, ConvertKit, etc.) for thought leadership
- [ ] Create a simple contact form or scheduling link (Calendly) on the homepage
- [ ] Add a "Recent Activity" feed pulling from GitHub, tweets, or a blog
- [ ] Experiment with a "Let's Work Together" modal on exit intent

## Accessibility & Mobile
- [ ] Audit contrast ratios and heading sizes on mobile
- [ ] Test keyboard navigation and screen reader compatibility
- [ ] Ensure all links have descriptive anchor text (avoid "click here")
- [ ] Verify touch target sizes are at least 44x44px on mobile

## Experimentation Ideas
- [ ] A/B test case study headlines (impact-first vs. context-first)
- [ ] Test different CTAs ("Let's Talk" vs. "Get in Touch" vs. direct email)
- [ ] Experiment with case study length—which depth resonates most?
- [ ] Try adding/removing the GitHub graph and measure engagement

---

**Priority**: Start with analytics (so you can measure impact of other changes), then narrative depth (case studies), then design polish.
